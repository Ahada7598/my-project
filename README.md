# Procurement Anomaly Detection System

Final Year Project - Government Contract Monitoring & Fraud Detection

## Live Demo
https://finalyearproject-smiu.streamlit.app/

## Features
- Multi-user authentication (Viewer, Admin, Buyer)
- Anomaly detection using ML algorithms
- Real-time bidding system
- Interactive visualizations
- SQLite database backend
